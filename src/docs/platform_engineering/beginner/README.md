## 进入条件

从会创建和保存文本文件开始。A01 会介绍终端、安装入口、文件位置和运行命令。

| [A01 文件、终端与第一段程序](./01_first_program.md) | 能创建、保存并运行一个程序，解释各行代码 |

## 本篇实践

独立完成一个任务积分小程序：输入一组虚构数据，使用结构体和集合组织，拒绝非法参数，为规则写测试，再把任务编码成 JSON。每一步只使用已经讲过的知识。

命令与代码是学习时执行的说明。A 篇的个人 go-course 目录与本仓库配套 labs 目录不同；进入整合示例时会明确提示工作目录。

## 如何判断可以继续

能逐行解释自己的程序，能预测一个未展示过的输入，能定位一次失败原因，并指出当前例子尚未覆盖的条件。只有复制代码能运行时，先继续练习，不急于添加新的组件。

把“已阅读”“已推导”“已运行”“独立变式通过”分别记录在[学习进度](../progress.md)。
