## 小需求：计算一次任务后的积分

用户原有 20 积分，完成任务增加 10。直接打印“30”只适用于这一组数字，我们希望让程序保存原积分和增量，再计算结果。

**值**是具体数据，例如 20；**变量**是程序里用于保存和访问值的命名位置；**类型**说明这类值允许哪些操作、如何解释。

## 常见数据类型

| 类型 | 表达什么 | 例子 |
|---|---|---|
| `int` | 整数 | 20、0、-3 |
| `float64` | 带小数的近似数值 | 3.5、0.25 |
| `string` | 文本 | `"task-1"` |
| `bool` | 真或假 | `true`、`false` |

float64 适合许多测量和科学计算场景，但不能精确表示所有十进制小数。积分练习使用整数，后续测量平均延迟时再使用带小数的数值。

`"20"` 是两个字符组成的文本，`20` 是可参与整数计算的数值。字符串拼接与整数加法使用相同的 `+` 符号，但含义由类型决定。

## 声明、赋值与零值

```go
var balance int = 20
var reward = 10
name := "学习函数"
```

第一行显式声明类型；第二行让编译器根据初始值推断类型；第三行用 `:=` 在函数内简短声明新变量。声明创建名字与值的关系，赋值用 `=` 修改已有变量。

```go
balance = balance + reward
```

先计算右边，再把结果放入左边。它不是数学里的恒等式，而是一条更新指令。`balance += reward` 是这个常见操作的简写。

没有提供初始值时，变量得到类型的零值：整数是 0，布尔是 false，字符串是空字符串 `""`。零值不自动表示业务合法，例如空用户 ID 可能需要拒绝。

## 完整程序与运行顺序

在 go-course 根目录创建 a02 子目录，将下列内容保存为 a02/main.go，再从根目录执行 `go run ./a02`：

```go
package main

import "fmt"

func main() {
    var balance int = 20
    reward := 10
    taskName := "阅读第一章"
    var finished bool

    fmt.Println(taskName, finished)
    balance = balance + reward
    finished = true
    fmt.Println("积分", balance, "完成", finished)
}
```

预期输出：

```text
阅读第一章 false
积分 30 完成 true
```

每一行运行后都可以画出变量表：balance 先为 20，计算后为 30；finished 先为 false，赋值后为 true。后续谈“状态变化”，就是在研究这些数据如何随操作改变。

## 运算与判断

整数支持加减乘除及 `%` 取余。`7/2` 的两个操作数都是整数，结果为 3；`7%2` 为 1。如果需要小数，须选择合适的类型和业务规则，不能假定整数除法会保留小数。

比较产生 bool：`balance > 0`、`balance == 30`、`balance != 20`。`==` 用于比较，`=` 用于赋值。逻辑与 `&&` 要求两边都成立；逻辑或 `||` 要求至少一边成立；`!` 取反。

逻辑与、或会短路：如果左边已决定结果，右边不再求值。A03 会用这些判断控制程序走哪条路径。

## 为什么还会看到 int64、byte 与 rune

`int` 的宽度与目标平台有关；`int64` 明确使用 64 位有符号整数。不同数值类型通常不能直接混用，需要明确转换：

```go
// 片段：放在 main 内。
var count int = 10
var total int64 = int64(count)
fmt.Println(total)
```

转换不是无限扩容。整数范围有限，大数运算需要检查越界；有符号 64 位整数最大值是 2 的 63 次方减 1。C01 会解释怎样在积分相加前检查它。

byte 是 uint8 的别名，用于表示一个字节；一个字节是 8 位二进制数据。rune 是 int32 的别名，常用于表示 Unicode 码点。A05 再结合中文文本解释字节与字符的区别。

`int64("10")` 不是合法的字符串解析。文本转数字需要解析规则并处理失败，A07 会介绍错误，之后才能正确阅读 `strconv.Atoi` 这样的转换工具。

## 常量与格式化输出

`const reward = 10` 声明不能被重新赋值的常量。适合表达程序中确定的固定值，不适合存放不断变化的余额。

`fmt.Println` 直接输出；`fmt.Printf` 根据格式串输出：

```go
// 片段：balance 已在 main 中声明。
fmt.Printf("余额=%d，类型=%T\n", balance, balance)
```

`%d` 表示十进制整数，`%T` 显示类型，`\n` 是换行。格式串里的占位符按顺序对应后面的参数。

## 练习与常见误解

1. 先加 10 再减 3，写出每一步余额。
2. 分别预测 `"10" + "20"` 与 `10 + 20` 的结果。
3. 声明一个没有初始值的字符串，用 `fmt.Printf("%q\n", value)` 观察带引号的结果。
4. 把已经声明的 balance 再写成 `balance := 50`，观察同一作用域内的声明错误，再改为赋值。
