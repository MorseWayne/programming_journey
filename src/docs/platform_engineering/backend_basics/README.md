## 进入条件

完成 A 篇，尤其是函数值、接口、指针、error、测试和 JSON。不会的概念应回到具体课补齐。

## 按阶段选取衔接内容

配合[学习路线](../curriculum/learning_path.md)时，S2 先读 B01–B02，再用 B06–B07 补齐基本并发与取消，随后进入 B03 的 HTTP 示例；S3 使用 B04–B05 认识环境与 SQL。下面按固定课号列索引，课号不代表必须逐项读完再实践。

每课先读小需求与概念，再预测示例结果，最后完成独立变化。主线不要求先去读另一套教程；官方资料用于核对和加深。

## 本篇实践

先说明程序、进程与通信，再正确等待有限的并发任务、解释共享与取消；随后阅读只读 HTTP 服务端与客户端，最后用 SQL 表表达持久任务。开始共享状态修改前检查同步与所有权，开始业务写入前补齐事务和权限。

命令与代码是学习时执行的说明。A 篇的个人 go-course 目录与本仓库配套 labs 目录不同；进入整合示例时会明确提示工作目录。

## 如何判断可以继续

能逐行解释自己的程序，能预测一个未展示过的输入，能定位一次失败原因，并指出当前例子尚未覆盖的条件。只有复制代码能运行时，先继续练习，不急于添加新的组件。

把“已阅读”“已推导”“已运行”“独立变式通过”分别记录在[学习进度](../progress.md)。
