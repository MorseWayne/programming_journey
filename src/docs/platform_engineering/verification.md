## 本轮教材重构

本轮交付是静态课程内容：七个阶段导读、业务场景地图、00–18 课正文、分层诊断、实践说明和学习记录。侧栏按学习阶段组织，原有章节地址保持可用。

内容审阅关注先修关系、术语解释、机制推导、实践预期和业务验收之间是否一致。静态检查覆盖本地页面链接、导航目标、代码围栏与折叠块配对。

本轮未执行站点构建，也未运行课程示例。新增顺序账户、索引造数和缓存迟到回填文件属于教学配套材料，正文中的输出均为预期结果，等待学习者实践验证。

## 学习时仍需独立验证

- 新增基础实验、索引练习和迟到回填练习的实际输出。
- 两会话锁等待、独立变式、业务领域唯一性和综合项目集成。
- Kubernetes 部署与恢复、镜像运行和真实模型接入。
- 真实多进程、网络故障与外部工具效果，不能由单进程模型推断。
- 网页交互的浏览器表现，不能由 Markdown 或纯模型检查替代。

将自己的版本、命令、结果和限制填写到[学习记录](./progress.md)，分别标明理论推导、参考示例运行与独立业务验证。
