## 本卷的定位与入口

先修：数学从集合、逻辑、计数与对数讲起；实现练习需要 Go 函数、循环与集合，链表还需要指针。按[学习路线](../learning_path.md)，S1 穿插 02.01–02.05，S4 进入树、堆、图及后续算法深化；不把证明、概率与摊还分析压在同一次入门课中。

现有入门讲解：A02–A06；原课程缺少独立主线。A/B/C/D 的具体链接见[原有讲解索引](../../concept_map.md)。本卷把这一领域拆成独立章节，每章还需要分次阅读、推导和练习。

## 本卷综合任务

为消息历史查询和有限发送队列比较数据结构，包含去重、优先处理与容量限制；用手算、性质和规模对照解释选择。

任务由学习者在具备环境时执行。理论推导、参考示例、个人实现和真实运行记录分别保存，故障与反例属于必需部分。

## 达到的能力

能说明算法为什么正确、什么时候退化、规模扩大后的资源成本；不以刷题数量作为能力证明。

用解释、最小实现、失败变式、业务取舍四类证据评审。只有目录、术语定义或参考代码通过，不能直接记为掌握本卷。

## 本卷章节展开规则

每章从一个明确问题开始，先补齐本章所需定义，再推导机制；至少含一条完整执行过程、一个反例、分层练习、反馈与业务迁移。复杂章节拆成多课，不把整卷知识压成一次速读。
