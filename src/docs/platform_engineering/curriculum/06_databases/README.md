## 本卷的定位与入口

先修：起步只需基本数据与集合概念，SQL 从本卷的基本语句讲起。按[学习路线](../learning_path.md)，S3 先学 06.01–06.03、06.10 的查询与资源管理，再学 06.07 的事务语义并回到事务 API；S4 补齐树、文件、页与内存后深入存储、执行、锁与恢复，S5 学复制迁移。

## IM 主线中的位置

以会话成员与消息记录学习关系/SQL 基础，再补文档模型与 MongoDB；对照实际存储时区分数据模型、确认与恢复边界。

主参照与源码入口见 [OpenIM 阅读地图](../im_reference.md)。下方章号继续用于知识定位；已有正文中的旧业务例子作为补充，独立章稿生成时按本节主线适配。

## 本卷综合任务

完成 IM 会话与历史数据方案，包含教学 SQL 模型、MongoDB 对照、索引、并发边界、写入确认、连接资源与迁移。

任务由学习者在具备环境时执行。理论推导、参考示例、个人实现和真实运行记录分别保存，故障与反例属于必需部分。

## 达到的能力

能从业务查询解释执行成本，能分析事务交错与恢复，而不仅是会写 CRUD。

用解释、最小实现、失败变式、业务取舍四类证据评审。只有目录、术语定义或参考代码通过，不能直接记为掌握本卷。

## 本卷章节展开规则

每章从一个明确问题开始，先补齐本章所需定义，再推导机制；至少含一条完整执行过程、一个反例、分层练习、反馈与业务迁移。复杂章节拆成多课，不把整卷知识压成一次速读。
