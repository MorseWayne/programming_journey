## 已完成的独立章稿

[03.01 数据、指令与存储层次](./01_data_instructions_storage.md)已完成，可在 01.04 后建立资源基础。位、单位、地址与缓存的必要定义都在本章给出，不要求先读 02.01 或掌握 Go 指针语法。[03.02 进程与系统调用](./02_process_syscalls.md)承接本地历史 CLI，说明程序启动、用户/内核边界、文件读取与退出。[03.03 Linux 进程与资源](./03_linux_process_resources.md)再用只读观察解释 PID、cwd、环境、描述符和信号。[03.04 CPU 调度](./04_cpu_scheduling.md)由进程状态进入可运行、等待、时间片和 IM 连接负载。[03.05 虚拟内存](./05_virtual_memory.md)在 S4 回访地址翻译、驻留与连接内存预算；[03.06 分配与映射](./06_allocation_mapping.md)再把 Go 对象、分配器、文件页和进程 RSS 对齐；[03.07 文件与目录](./07_files_directories.md)用日志轮转区分名字与打开对象；[03.08 持久化机制](./08_persistence_mechanisms.md)再把名字切换与崩溃恢复分开；[03.09 I/O 与事件通知](./09_io_event_notification.md)用两连接解释就绪、短读写和完整消息。

03.01 含 8 节、16 道练习和明确假设的缓存/预算推演；03.02–03.09 各含 8 节、22 道练习，分别沿本地文件、进程现场、单核调度、虚拟内存、分配映射、文件轮转、崩溃恢复与事件 I/O 模型推演。03.10–03.12 仍按下方设计展开；系统诊断与隔离限制在相应阶段回访。

## IM 主线中的位置

长连接的描述符、进程与线程、消息缓冲、内存保留、日志和磁盘；把症状与资源机制对应。

主参照与源码入口见 [OpenIM 阅读地图](../im_reference.md)。下方章号继续用于知识定位；已有正文中的旧业务例子作为补充，独立章稿生成时按本节主线适配。

## 本卷综合任务

围绕 IM 网关的连接、内存或磁盘症状编写诊断说明，包含假设、只读观测、最小复现与恢复验证。

任务由学习者在具备环境时执行。理论推导、参考示例、个人实现和真实运行记录分别保存，故障与反例属于必需部分。

## 达到的能力

能把应用现象追踪到资源与机制，并说明观测数据的单位、视角和局限。

用解释、最小实现、失败变式、业务取舍四类证据评审。只有目录、术语定义或参考代码通过，不能直接记为掌握本卷。

## 本卷章节展开规则

每章从一个明确问题开始，先补齐本章所需定义，再推导机制；至少含一条完整执行过程、一个反例、分层练习、反馈与业务迁移。复杂章节拆成多课，不把整卷知识压成一次速读。
