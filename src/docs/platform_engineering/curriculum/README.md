本系列以 Go 为主要实践语言，用虚构 IM 需求串起语言、算法、系统、网络、数据库、并发、分布式、工程交付、可靠性和架构判断。[OpenIM 固定版本与源码阅读地图](./im_reference.md)提供公开项目参照。全部 **14 卷 × 每卷 12 章 = 168 章独立正文**已齐备。

## 两种导航各负其责

[阶段学习路线](./learning_path.md)是实际阅读顺序：S0–S7 按先修跨卷推进，逐阶段交付 P1–P5；AI 是按需求进入的扩展方向。卷号用于按领域查找机制，不要求初学者先通读一整卷再进入下一卷。

每卷按起步、原理、工程、进阶四层展开。先讲术语与最小模型，再推导成立条件和反例，随后把知识用于 IM 需求、失败路径、测量和取舍。第一次阅读只完成当前阶段需要的内容；泛型、反射、复杂算法和平台专题可在具备前置后第二遍深化。

## 从一条需求进入理论与实践

消息变多时引入集合与查找；历史要跨进程保存时学习数据库与持久化；两端通信时学习网络与并发；响应丢失时分析重复和结果未知；设备离线时设计保留、补拉与确认。每次先说清旧方案在哪个条件下失效，再增加机制，并记录正常、失败与恢复的可复核证据。

开始阅读：[01.01 程序、源代码与一次运行](./01_go/01_program_toolchain.md)。不确定前置位置时查[概念索引](../concept_map.md)；项目实践先看[环境页](../environment.md)。经典资料的覆盖和官方查阅入口见[资料调研](./source_review.md)，教材状态与个人能力验收见[编写状态](./assessment.md)。
