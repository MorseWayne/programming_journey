## 已完成的独立章稿

[14.01 Python 与数据工作](./01_python_data_work.md)已完成。它面向 Go 初学者，用完全虚构的 IM JSONL 补齐 Python 对象、函数、异常、UTF-8、字段/权限校验与可复现数据清单。[14.02 必要数学与机器学习直觉](./02_math_ml_intuition.md)从人工二维向量进入余弦、条件概率、分类指标、训练/验证和泄漏。[14.03 语言模型基础](./03_language_model_foundations.md)分清 UTF-8 字节、token、模型向量、上下文与生成文字和 IM 业务事实。[14.09 评测与数据工程](./09_evaluation_data_engineering.md)先建立虚构问题、资料权限和关键词基线，再为学完 RAG 后的组件/端到端评测留第二遍。[14.04 Transformer 与推理路径](./04_transformer_inference_path.md)用可手算注意力和 KV 缓存估算连接模型机制与业务权限。[14.05 提示与结构化输出](./05_prompt_structured_output.md)从指令与示例走到 JSON 契约、分层校验和安全回退。六章各含 8 节讲解、22 道分层练习；接着进入 14.06 检索与索引。

本卷实际顺序：14.01–14.03 → 14.09 的数据集与基线起步 → 14.04–14.07 → 回到 14.09 深化组件和端到端评测 → 14.08 工具工作流 → 14.10、14.12。14.11 按需求选修。评测在首次比较方案之前开始，涉及工具副作用时再检查恢复前置；章节编号继续用于稳定定位。

## 本卷综合任务

从固定文档与查询集发展到聊天中的资料助手，再引入受控工具；记录权限、证据、版本、质量、成本与恢复。

任务由学习者在具备环境时执行。理论推导、参考示例、个人实现和真实运行记录分别保存，故障与反例属于必需部分。

## 达到的能力

能分辨模型、数据、检索、执行和产品需求的不同失败，并用独立评测决定改进。

用解释、最小实现、失败变式、业务取舍四类证据评审。只有目录、术语定义或参考代码通过，不能直接记为掌握本卷。

## 本卷章节展开规则

每章从一个明确问题开始，先补齐本章所需定义，再推导机制；至少含一条完整执行过程、一个反例、分层练习、反馈与业务迁移。复杂章节拆成多课，不把整卷知识压成一次速读。
