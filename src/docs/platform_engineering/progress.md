## 四次篇章回顾

| 篇章 | 能够独立说明与完成的任务 |
|---|---|
| A | 保存并运行程序；组织数据与函数；处理错误；复用包并写测试；读写 JSON |
| B | 解释进程与状态位置；沿 HTTP 调用读代码；理解环境与 SQL；协调并发和取消 |
| C | 从业务规则推导同步、事务、缓存、重试、接管、测量和发布 |
| D05–D06 | 根据约束比较方案，完成综合交付与答辩 |
| D01–D04 | 按 AI 方向区分检索、生成与工具效果，建立评测 |

A、B 篇不要求先会其内容；它们就是学习起点。C 篇每个单元还有较小验收，见课程侧栏导读。

## 复习时改变一个条件

可以隔一天解释机制，一周后做变式，一个月后迁移到另一小需求。间隔按实际情况调整。

例如先让 reward 从 10 变成 0，再让字段缺失；掌握后才增加两个并发请求或一个远程失败。一次改变太多条件，会让你很难判断究竟是哪一步没理解。

数据库、集群和真实模型等条件实践单独记录。未执行不能算通过，也不妨碍继续完成独立的理论阅读。
