这是一套面向已有 Go 业务开发经验、希望承担完整公共服务平台的实践课程。学习场景包括游戏会话、邮件、匹配、配置、消息和 AI 内部工具；所有代码均为原创教学模型，使用虚构业务与数据。

完成课程后，你应能解释请求的状态变化，验证并发与数据一致性，在故障下恢复服务，并交付一个可评测的 AI 工具。课程按每周 6–8 小时、24 周设计，已经掌握的部分可以通过入门诊断与实验验收后跳读。

## 从这里开始

1. 阅读[学习方法与入门诊断](./study_guide.md)，建立自己的学习记录。
2. 按[实验环境](./environment.md)运行第一组检查。
3. 从[第 1 课：请求、状态与契约](./01_contracts.md)开始，先预测，再运行，再解释。
4. 每完成一个阶段，回到[进度与复习记录](./progress.md)填写证据。

## 每课怎样学习

每课都给出问题、前置知识、可观察目标、循序解释、运行步骤、预期现象、独立练习、折叠提示和反馈。读完参考答案只能记为“已阅读”；用不同输入独立复现并解释边界，才记为“已掌握”。

实验在仓库根目录的 `labs/platform_path/`。Go 和 Python 核心实验无需外部依赖或模型密钥；MySQL/Redis 实验使用独立 Docker Compose 环境。Kubernetes 与真实模型接入属于条件实验，环境要求和验收边界在对应章节说明。
