这套课程面向 Go 初学者，以虚构 IM 业务和固定版本的 [OpenIM](./curriculum/im_reference.md) 源码为参照，从程序入门逐步走向系统设计与长期维护。消息、会话、权限、离线补拉等教学数据和规则均为虚构；学习时须区分教学模型、公开项目事实和个人实际运行结果。

## 从哪里开始

1. 按 [S0–S7 学习路线](./curriculum/learning_path.md)选择当前阶段，跨卷学习所需前置。
2. 从 [01.01 程序、源代码与一次运行](./curriculum/01_go/01_program_toolchain.md)开始；遇到陌生术语可查[概念与先修索引](./concept_map.md)。
3. 每章按“业务问题 → 基础理论 → 小例子与反例 → 个人实践 → 结果复核”推进。学习方法见[学习指南](./study_guide.md)，环境准备见[实践环境](./environment.md)。

[14 卷总纲](./curriculum/README.md)用于按领域找章节；学习顺序以阶段路线为准。当前 **14 卷、168 章独立正文**均已齐备，[编写状态与能力验收](./curriculum/assessment.md)说明教材完成与个人掌握的区别。

## 一条逐步扩展的 IM 主线

| 阶段 | 先解决的业务问题 | 阶段成果 |
|---|---|---|
| S0–S1 | 如何校验消息、组织会话与本地历史？ | P1：可解释、可测试的本地消息工具 |
| S2–S3 | 两端如何通信、谁有权发送、历史如何保存？ | P2：从内存通信逐步进入可信接口与持久历史 |
| S4–S5 | 慢接收方、重复发送、离线和多设备怎样影响保证？ | P3：有资源边界和故障恢复证据的消息链 |
| S6–S7 | 如何发布、排障、迁移并长期维护？ | P4 运行交付与 P5 架构答辩 |
| AI 选修 | 如何在聊天中提供有权限、有证据的助手？ | 独立评测的资料助手与受控工具 |

[虚构业务地图](./business_map.md)统一教学对象和问题；[个人学习记录](./progress.md)用于分别记录阅读、推导、运行和独立变式。进度页不会因为教材已写完而替学习者标记“已掌握”。

## 资料与边界

经典书籍与官方资料怎样融入各卷，见[资料调研与官方查阅入口](./curriculum/source_review.md)。课程正文是静态教材，示例的运行、性能数据、OpenIM 源码对照和生产适用性应按各章说明分别验证。
