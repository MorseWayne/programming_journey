## 要解决什么问题

资料助手先给出可追溯证据，再在可信授权后承担工具动作。

## 已经学过的知识

完成 A、B 篇，并理解 C06 事务、C08 部分失败、C10 指标与 C12 身份。Python 由 D01 从语法差异开始讲。

遇到术语断层时，通过[概念与先修索引](../concept_map.md)找到完整基础课。

## 顺序与目标

本组是[学习路线](../curriculum/learning_path.md)的方向扩展。先读 D01，再从 D04 学习数据集与基线部分，随后学 D02、D03，并回到 D04 深化组件与端到端评测；首次比较方案之前就确定如何评价。

| 课程 | 理解重点 |
|---|---|
| [D01 Python 工程基础](../13_python.md) | 对照已学 Go 理解对象、异常与资源 |
| [D02 检索与证据](../14_rag.md) | 从词项基线理解向量、分块与生成 |
| [D03 工具与工作流](../15_agents.md) | 解释权限、状态与副作用恢复 |
| [D04 评测](../16_evaluation.md) | 区分检索、回答和任务效果 |

## 学习与实践怎样交替

先读每课开头的需求，再回顾先修表；学一个机制，就解释一个最小例子和变化条件。随后阅读实验步骤并写出预测，具备环境后实际验证。工程深化在当前机制解释清楚后进行。

## 单元验收

展示误命中、证据不足、权限拒绝和重复执行案例，明确是否真的使用了模型。

不能解释失败原因时，先回到较小例子。阅读、理论推导和运行记录分别填写，参考示例通过不等于个人变式已经通过。
