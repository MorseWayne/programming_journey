## 技术修订

- 初稿导出有重复 `###` 标题和大段同义重述；正式页重排为语言前置→对象→函数异常→JSONL/字节→权限校验→复现→最小管线。
- 初稿后段称 4096 B 可能指**整个 HTTP 报文含请求行和头部**，与本系列“原始 HTTP **请求正文**最多 4096 B”冲突。正式页严格限定请求正文，并指出离线 JSONL 的 `body` 不能回推当时的原始请求字节。
- 初稿建议在 JSONL manifest 中填 `raw_request_body_bytes`，但示例只有离线导出字段，没有原始 HTTP 请求；正式页不伪造这一数值，只有实际抓到原始请求正文时才能检验 4096 B。
- 初稿有将 JSONL 原始行全文放入拒绝记录的示意，可能扩散私密正文。正式页拒绝报告只记行号/字段或异常类别，原始输入另受控保留；本课程只用虚构内容。
- 初稿局部把同 `message_id` 重复行直接记 `duplicate_message_id`，但不能从导出行断言线上发生同 ID 重复请求及 409。正式页保留冲突/来源核查，线上响应须另有请求证据。
- 类型注解不强制运行时字段类型、UTF-8 字节不等于字符数、SHA256 不证明权限/脱敏三项均由 Python 官方文档校核，正式页写明其边界。
