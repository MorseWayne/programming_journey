## 单章覆盖与教学审阅

- 从具体 `FindMessage` 的重复遍历动机进入 `First[T any]` 完整示例，逐行解释声明、实参推断、`func(T)bool`、`zero,false` 与 `any` 不保证 `ID` 字段。
- 用 `MessageID string`、`~string`、`Set[K comparable]` 和 `~int64|~string` 的可用操作讲类型集合；明确 `[]byte` 不可比较、`nil` map 不能写，以及接口动态不可比较值的进阶 panic 边界。
- 泛型 `Queue[T]` 仍需容量、底层切片滞留和并发控制；`slices.Clone/maps.Clone` 为浅复制，保留此前切片共享前置。
- 对比具体函数、小接口、泛型与 Go 1.21+ `slices/maps`，不让类型参数隐藏当前重复 ID 409 或正文 6 UTF-8 B 合同。
- 复核 Go 1.27 官方发布说明：具体方法现在可**自行声明**类型参数；泛型类型接收者沿用已有参数自 Go 1.18 起可写；接口方法仍不能声明类型参数。旧教材的“Go 没有泛型方法”不能无版本条件照搬。
- 8 节从概念到版本边界，22 题分基础、约束/容器、业务取舍三层；01.12 CLI 基础版不要求先学本章。

## 原稿对账与修订

- 原稿前段正确说明 Go 1.27 **具体类型的方法可自行声明新类型参数**，结尾却写成“Go 1.27 方法不能额外引入独立的新类型参数”。已核 [Go 1.27 官方发布说明](https://go.dev/doc/go1.27)与 [Generic Methods 官方文章](https://go.dev/blog/generic-methods)：新能力确实存在，接口方法仍不能声明类型参数；正式页保持正确的版本条件。
- 原稿把 `comparable` 概括成“所有类型参数的值都安全可比”，遗漏 Go 1.20 起接口类型实参满足约束的例外：接口动态值若不可比较，实际比较仍可能 panic。正式页在基础用法后单列这一进阶边界，业务 ID 保持静态 `MessageID`。
- 原稿以大量重复段落说明 `First`、`Set`、`Queue`，并重复小标题；正式页保持“具体重复→完整泛型函数→约束/类型集合→容器→标准库/接口取舍→版本第二遍”的初学者路径。
- 原稿称浅复制可避免对原集合增删改，若元素仍含指针、切片或映射则这一说法过宽；正式页明确 `slices.Clone/maps.Clone` 仅复制外层，嵌套可变数据仍共享。
- 原稿正确保留泛型不改变 S2 重复 ID 409、6 UTF-8 B、队列容量和并发安全的业务/资源边界；正式页继续以这些条件决定是否值得抽象。
