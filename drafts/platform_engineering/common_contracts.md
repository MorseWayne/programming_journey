# 并行章稿的共同教学约定

适用范围：01.03 之后的 IM 起步章稿。它记录已有教材明确采用的简化规则，方便各章保持一致；不能当作 OpenIM 的生产协议。

## 本地文本校验

| 项目 | 现有约定 |
|---|---|
| 会话分类 | 综合程序使用 single、group 两个教学字符串，未知分类拒绝 |
| 整体优先级 | 先判断会话分类，再调用文本校验 |
| 文本内部优先级 | maxBytes 必须大于 0 → 原始文本非空 → len(body) 不超过 maxBytes |
| 长度单位 | Go 字符串的字节数，不是码点或视觉字符数 |
| 等于上限 | 合法 |
| 空格 | 不自动修剪；一个空格按当前规则可以合法，但仍占字节 |
| 函数契约 | validateText 返回 bool、string；通过为 true 与空原因，拒绝为 false 与原因 |
| 效果范围 | 只得到本地校验结论，没有网络、可信身份、持久性或交付保证 |

原因文字可以为本章阅读适当调整，拒绝分类和优先级须一致。新增通知类别、字符限制、UTF-8 有效性、计数上限或其他业务规则时，标注为新的教学需求，再同步定义和案例。

## 需要保持的概念边界

- 用户、设备、连接与会话分别定义，不能用一个编号悄悄替代所有身份。
- nil、空集合、缺失、合法零值与无效状态分别解释。
- 变量名不能决定推断类型；参数值复制不代表所有底层数据都完全独立。
- 作用域描述名字可见范围，不能据此断言某块内存立即释放。
- 发送受理、持久条件、设备处理与用户已读分别定义；本地成功次数不是已送达消息数。
- 初始状态已不合法时，拒绝并保持原状不等于修复了不变量。
- 01.04 才展开数组、切片和 range；01.05 展开 map、结构体和指针；方法、接口与 testing 的先修继续按路线安排。

## 来源与教材状态

实际引用 OpenIM 时固定版本与文件，只说明已核对范围。生成器收到人工整理的事实摘要，不等于它已自行读取整个仓库或已导入知识库。

新增正文经过生成、审阅、项目同步、统稿与静态检查后计为交付。所有代码、终端输出与业务案例在本次教材工作中仍是静态预期，未执行即不标记运行通过。

## 对象、算法与资源的衔接

第二批起，以下约定用于连接语言、数学与系统课程：

- 稳定消息身份与列表位置分别说明；map 的键唯一性只在当前容器及所选键规则内成立，不能直接推断跨请求或跨节点去重。
- map 缺失、存在零值、存在 nil 指针分别解释；对象复制、嵌套共享、修改所指对象和给指针变量重新赋值分别追踪。
- 成员数、设备数、消息数、投递尝试、队列项和网络包分别计量。扇出模型写清是否排除发送者、设备假设和在线条件。
- 算法操作计数依赖选定基本操作；字符串长度可变时，不能无条件把完整比较视为固定成本。渐近模型不提供真实耗时或吞吐数字。
- 平均分析需要说明输入分布，摊还分析需要说明操作序列与增长模型；不能把教学中的几何增长当作 Go 规范规定的具体扩容算法。
- 数据大小和速率明确 bit/byte、十进制与二进制单位。原始正文、序列化载荷、元数据、副本和进程资源量分别核算。
- CPU 缓存、应用缓存、主内存、存储介质分别定义；局部性结论带工作集和访问假设。Go 切片的元素连续不等于所有关联文本字节连续。
- 纸面缓存与缓冲模型注明简化参数，源码阅读只支持已看到的操作；没有测量就不声称实际时延、分配量或 RSS。

三章独立展开自己首次使用的必要词汇，不能把同批另一章的未交付知识默认为已掌握。跨章数学符号也要与 Go 运算符区分，例如数学乘方记号不能原样当成 Go 的异或运算。
